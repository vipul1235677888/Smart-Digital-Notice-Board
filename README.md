# Smart Digital Notice Board System

A full-stack DBMS project built using PHP, MySQL, HTML and CSS.

## Features
- Priority-based notice management (Urgent / Normal / Low)
- Automated notice scheduling and expiry
- Department-wise and category-wise filtering
- Student acknowledgement tracking
- Admin dashboard with read percentage stats
- Audit log auto-generated by MySQL triggers
- Role-based access (Admin / Staff / Student)

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP 8
- **Database:** MySQL 8 via phpMyAdmin
- **Server:** Apache (XAMPP)

## How to Run
1. Install XAMPP
2. Copy project folder to `C:\xampp\htdocs\notice_board\`
3. Import `notice_board_db.sql` in phpMyAdmin
4. Start Apache and MySQL in XAMPP
5. Open `http://localhost/notice_board/login.php`
